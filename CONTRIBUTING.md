# Помочь проекту

Баги, понятные примеры и небольшие исправления приветствуются.
Для сообщения об ошибке нужны версия ОС, X11/Wayland, команда воспроизведения,
ожидаемое и фактическое поведение. Прикладывайте только относящийся к ошибке фрагмент
лога, заменив личные пути, адреса и секреты примерами.

## Локальная разработка

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[ui,test]'
.venv/bin/python -m pytest -q
```

Для изменения одного компонента достаточно связанных проверок, например:

```bash
.venv/bin/python -m pytest -q tests/test_events.py tests/test_gui.py
```

Qt-тесты используют offscreen и не доказывают поведение оконного менеджера.
Проверяйте изменения рабочего стола в настоящей сессии. Удалённые интеграции
проверяются только при существующем разрешённом доступе.

## Важные договорённости

- Развиваем наблюдение, прогресс и доставку результатов. HUD не управляет остановкой,
  перезапуском или паузой вычислений.
- Сохраняем компактный внешний вид, независимое окно подробностей и Undo без
  повторного запуска работы.
- Ошибка, потеря связи и неизвестный исход — разные состояния.
- Автоматическое продолжение Codex остаётся явным выбором пользователя.
- В описание изменения включайте причину, проведённую проверку и ограничения.

GitHub Actions проверяет Linux и Python 3.10/3.12 при push и pull request.
Результаты доступны на [вкладке Actions](https://github.com/ViskyG/process-hud/actions).
