# Что действительно проверено

Сводка локальных проверок версии 0.1.0, выполненных до подготовки публичного
репозитория. Личные пути, идентификаторы диалогов, серверы и исходные журналы
в публичную копию не включены.

| Область | Реально проведённая проверка |
| --- | --- |
| GNOME/X11 | Прозрачность, поверх окон, рост высоты, отдельные подробности, перенос между двумя мониторами, скрытие и показ |
| Курсоры и Undo | Измерены разные X11-курсоры над заголовком, списком и крестиком; настоящий клик и Ctrl+Z вернули строку с тем же живым PID |
| Выход из GUI | Выход и повторный запуск сохранили видимость; вычисления не затрагивались |
| Локальные процессы | Прогресс, логи, успех, ошибка, сигнал, дочерние процессы, PID attach и удаление строки без остановки |
| Автопродолжение | Успех, ошибка с кодом 7, SIGTERM с wait status −15 и неизвестный исход доставлены в исходный диалог |
| Перезагрузка редактора | Ожидавшее событие пережило перезагрузку окна и доставилось один раз после подключения |
| Занятый агент | Ошибка и SIGTERM пришли отдельными событиями в уже активный ход |
| Субагент | Реальная двухминутная задача субагента вернула результат корневому агенту |
| Docker | Чтение состояния и логов существующего контейнера через доступный daemon |
| Уведомления и звук | D-Bus-вызовы, звуковой поток и соблюдение GNOME «Не беспокоить»; пользователь слышал звук |

## Проверка ожидания без работы модели

| Сценарий | Пауза | Новые модельные ходы | Обновления счётчиков токенов |
| --- | ---: | ---: | ---: |
| Обычный диалог | 120,1001 с | 0 | 0 |
| Субагент → корневой агент | 120,1001 с | 0 у обоих | 0 у обоих |

В обоих сценариях процесс завершился успешно, результат был прочитан, строка
удалена, логи сохранены. Это наблюдение за конкретными диалогами, без измерения
квоты всего аккаунта. Скрипт воспроизведения — `scripts/codex_idle_experiment.py`;
он требует активного разрешённого моста и создаёт локальные записи с ID сеансов.
Такие исходные записи не следует коммитить.

## Автотесты

47 связанных проверок моста, runtime, событий, хранилища и уведомлений прошли
с настоящими локальными процессами и моделью App Server в виде программной
фикстуры. Дополнительные проверки Qt, CLI, парсера внимания и restore выполнялись
только для соответствующих исправлений. Эти наборы пересекаются; их количества
не суммируются в число уникальных тестов.

Фикстура App Server не вызывает модель. Offscreen Qt не доказывает поведение
GNOME. Эти проверки учитываются отдельно от перечисленных выше живых испытаний.

## Пока не проверено

- Реальная Kubernetes Job: в локальном окружении не было доступного API.
- Реальная `run-ssh`: на доступном хосте не было headless HUD; новую инфраструктуру
  для проверки не создавали.
- Физический сон системы и принудительные обрывы реальных удалённых соединений.
  Логика потери/возврата связи и границы ожидания проверены фикстурами.
- Windows, macOS, полноценная работа HUD на Wayland, другие клиенты Codex.
- Нативная цепочка вложенных субагентов: есть модульные проверки родительской
  цепочки, живой тест проведён для одного уровня.

Прямое пробуждение завершившего ход субагента в первом эксперименте было отклонено
App Server. Рабочее решение адресует результат корневому владельцу задачи.
Общая экономия токенов или квот в процентах для Process HUD не измерялась.
