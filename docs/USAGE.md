# Справочник

## Запустить работу

```bash
process-hud run --title "Тесты" --cwd /absolute/project -- \
  /absolute/project/.venv/bin/python -m pytest tests/integration
```

Замените пути реальными. Команда возвращает ID после подтверждения запуска
наблюдателя; её результат ещё впереди. `--key UNIQUE_OPERATION_KEY` защищает от
случайного повторного запуска с теми же параметрами. Команды не исполняются через
shell неявно; для конвейера используйте явный `bash -o pipefail -c '...'`.
Управляемая задача получает закрытый stdin: взаимодействие с терминалом здесь не подходит.

## Посмотреть результат и убрать запись

```bash
process-hud report ID --tail 40
process-hud logs ID --tail 100
process-hud remove ID
process-hud restore ID
process-hud list --all
```

`ID` — полный идентификатор из запуска. `remove` скрывает запись и сохраняет логи.
Управляемый процесс продолжает работу. Наблюдение за внешним источником может
отсоединиться; `restore` восстанавливает наблюдатель без повторного запуска задачи.
Ctrl+Z возвращает строки, убранные через GUI, в пределах текущего сеанса интерфейса.

`purge ID --yes` удаляет сохранённые логи только после удаления строки и выхода
наблюдателя. Используйте его только когда удаление логов действительно нужно.

## Подключить существующую задачу

```bash
process-hud attach --title "Импорт" --pid 12345 --log-file /absolute/import.log
process-hud attach-docker --title "Контейнер" --container actual-container
process-hud attach-k8s --title "Job" --context actual-context --namespace actual-namespace --job actual-job
```

| Источник | Что можно узнать | Ограничение |
| --- | --- | --- |
| Управляемый процесс | stdout/stderr, код выхода, измеренный прогресс, дочерние процессы | Linux; нет гарантии пережить logout, reboot или очистку cgroup |
| Существующий PID | Жив ли именно этот процесс, указанный лог | Исторический код выхода восстановить нельзя |
| Docker | Полный ID, состояние, логи и код выхода контейнера | Нужен доступ к Docker daemon |
| Kubernetes Job | Контекст и UID Job, финальные условия и логи | Нужны kubectl и права чтения; ошибка Pod не всегда означает ошибку Job |
| SSH | Удалённый HUD ID и отчёт, восстановление наблюдения после связи | Нужен headless HUD на сервере и существующий SSH-доступ |
| Внешняя программа | Явные `register`, `progress`, `attention`, `finish` | Программа отвечает за достоверность сообщений |

Неизвестный исход остаётся неизвестным. Потеря соединения сама по себе не означает
падение задачи. `recover` восстанавливает отсутствующие наблюдатели, а не вычисления.

## SSH и сервер без GUI

На разрешённом Linux-сервере из исходников:

```bash
bash install.sh --headless
```

Локально, с реальным SSH-алиасом и путями:

```bash
process-hud run-ssh --title "Удалённые тесты" --host actual-ssh-alias \
  --remote-bin /home/actual-user/.local/bin/process-hud \
  --cwd /absolute/project -- python3 -m pytest
```

`attach-ssh --remote-id ID` подключает уже существующую удалённую запись HUD.
Проверка host key сохраняется. Если подтверждение запуска потерялось, команда
не отправляется повторно: наблюдатель читает заранее выбранный ID.

## Настоящий прогресс

Программа может печатать строки с JSON и своевременным flush:

```text
@@HUD {"current":250,"total":1000,"unit":"rows","phase":"Импорт"}
```

Либо использовать Python API, если пакет установлен в окружение самой программы:

```python
from process_hud.api import Reporter

hud = Reporter()
hud.update(current=250, total=1000, phase="Импорт", unit="rows")
```

HUD не подмешивает свой Python в окружение задачи. ETA появляется по измерениям;
устаревшая оценка скрывается. 100% не заменяет финальный код выхода.
`run --parser percent` включайте только для вывода, где проценты относятся именно
к этой работе. По умолчанию произвольные числа из логов не считаются прогрессом.

## Когда нужен агент

С установленным мостом флаг `--resume-codex` доступен для run, attach и register.
Запуск выполняется из настоящего диалога Codex. Можно добавить
`--attention-after 600`: один запрос внимания через десять минут, без остановки работы.
Программа может явно сообщить:

```text
@@HUD {"attention":"Нужно решение о следующем этапе"}
```

Или вызвать `Reporter().attention("причина")` / `process-hud attention ID --message "причина"`.
Для обработанного события при продолжающейся работе используется
`process-hud acknowledge ID --event EVENT_ID`; активная строка остаётся видимой.
При финальном результате агент читает отчёт и убирает строку.

## Окно и звук

```bash
process-hud ui show
process-hud ui hide
process-hud ui quit
process-hud config --opacity 0.24 --width 294
process-hud config --notify on --sound on
```

`ui ensure` уважает скрытое состояние; запуск задачи уже вызывает его автоматически.
Только явный show раскрывает скрытый HUD. Верхний край служит для переноса,
правый — для изменения ширины. Контекстное меню содержит настройки уведомлений.
Звук зависит от возможностей рабочего стола; режим «Не беспокоить» не обходится.

## Данные и удаление

Состояние хранится в `$XDG_STATE_HOME/process-hud` (обычно `~/.local/state/process-hud`).
Внутри — SQLite и ограниченные по размеру логи. Они могут содержать аргументы
и секреты, которые вывела сама задача; перед публикацией проверяйте их содержимое.

```bash
process-hud doctor
bash uninstall.sh
```

Диагностика не меняет систему. Удаление установки требует завершённых наблюдателей
и закрытого GUI, архивирует установку и skill, сохраняет записи и логи.
Для отключения моста сначала выполните [его откат](CODEX_BRIDGE.md#отключить-мост).

## Если установка или окно не запускается

На Ubuntu модуль виртуальных окружений устанавливается пакетом `python3-venv`.
Если Python сообщает об отсутствии `venv`/`ensurepip`, установите этот пакет
обычным менеджером пакетов и повторите `bash install.sh`.

`process-hud doctor` показывает доступные компоненты. Причина ошибки открытия окна
сохраняется в `~/.local/state/process-hud/ui.log`. Если Qt сообщает об отсутствующей
системной библиотеке, установите соответствующий пакет для своего дистрибутива;
переустанавливать весь HUD для этого не требуется. Приложение и его окружение
находятся в `~/.local/share/process-hud/venv`.
