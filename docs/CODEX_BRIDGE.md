# Продолжение Codex по событию

Экспериментальная локальная интеграция для **Codex в VS Code на Linux x86_64**.
Она использует App Server уже установленного расширения. Это отдельный режим,
который включается пользователем для подходящих фоновых операций.

## Подключение при первом использовании

Обычно ничего отдельно включать не нужно: после `bash install.sh` skill
`$process-hud` сам проверяет живой мост **для текущего диалога** перед первой
фоновой задачей с автоматическим продолжением. Если моста ещё нет, агент
запускает установщик из установленной программы:

```bash
~/.local/share/process-hud/venv/bin/python ~/.local/share/process-hud/scripts/install_codex_bridge.py --ensure
```

Этот скрипт идемпотентен: уже настроенный мост он не переустанавливает, сохраняет
резервные копии настроек и не заменяет конфликтующее значение
`chatgpt.cliExecutable` без разбирательства. Для ручной установки подходит та же
команда.

При **первой** настройке необходимо один раз перезагрузить окно VS Code.
Обёртка должна запускаться вместе с Codex App Server, поэтому уже работающий
App Server нельзя подключить к ней задним числом одним изменением файла настроек.
После перезагрузки skill проверяет собственный диалог вызовом:

```bash
~/.local/share/process-hud/venv/bin/python -c 'from process_hud.codex_bridge import current_origin; print(current_origin()["thread_id"])'
```

Значение `CODEX_THREAD_ID` берётся из рабочего окружения Codex; указывать его
вручную не нужно. Общая установка обслуживает несколько диалогов одного
пользователя и направляет события правильному владельцу. Установщик сохраняет
резервные копии в `~/.local/share/process-hud/bridge-backups/` и указывает
VS Code `chatgpt.cliExecutable` на `venv/bin/process-hud-codex`.
Автозапуск вычислений и существующие учётные записи не меняются.

Текущая установка моста рассчитана на стандартные каталоги VS Code и HUD.
VS Code Insiders, другие клиенты, нестандартные каталоги и другие ОС не проверены.

## Работать

После разрешения пользователя агент запускает из своего диалога:

```bash
process-hud run --title "Импорт" --resume-codex --key unique-import-input -- python import_data.py
```

Запуск проверяет настоящий `CODEX_THREAD_ID`, доступный мост и владельца диалога.
Для субагента проверяется цепочка родительских метаданных; результат адресуется
корневому агенту. Прямое пробуждение завершившего ход субагента не используется.
Никакого выбора диалога по имени проекта или PID нет.

Агент завершает ожидающий ход. За состоянием следят локальные программы; при
результате мост отправляет один структурированный `toolOutput` через `turn/start`.
Если ход уже активен, App Server ставит вывод в его очередь — это предусмотрено
[официальным протоколом](https://learn.chatgpt.com/docs/app-server#start-a-turn).
Возобновлённая генерация расходует токены обычным способом.

## Какие события приходят

- `process_hud_completion`: подтверждённые успех, ошибка или прерывание.
- `process_hud_attention`: неизвестный финальный исход, потеря наблюдателя,
  потеря связи дольше 30 секунд, явный запрос программы или предупреждение
  `--attention-after SECONDS`, если пользователь/агент задал такой срок.

Внимание не означает завершение или ошибку. Агент читает текущий `report` один раз,
сверяется с последними указаниями пользователя и подтверждает обработку события.
Продолжающаяся задача остаётся видимой; обработанный финальный результат убирается.
Удаление строки до доставки dismiss-ит продолжение, не останавливая процесс.
Undo возвращает наблюдение; уже принятые события повторно не отправляются.

## Доставка и приватность

Мост использует приватный Unix-сокет текущего пользователя. Учёт принятых событий
подавляет повторы. Подтверждение `accepted` ещё не означает, что агент прочитал
результат. При неоднозначном подтверждении (`uncertain`) автоматической повторной
отправки нет. Это состояние видно в подробностях задачи и требует проверки диалога.

Ожидающий результат доставляется после восстановления подключения, если исходный
диалог загружен. Повторные попытки ограничены 24 часами на событие. При старте
нового моста восстанавливаются отсутствующие локальные наблюдатели доставки;
вычисления повторно не запускаются. Пережить logout/reboot/убийство cgroup
программа не обещает. Разные задачи доставляются отдельными событиями.

Аудит содержит жизненный цикл диалогов/ходов и счётчики токенов, без текстов
запросов, команд и логов задач. Сами отчёты задач могут содержать личные данные.
HUD не интерпретирует произвольный текст пользователя как команду отмены:
агент снимает связанные записи, когда задание отменено или утратило актуальность.

## Отключить мост

Закройте соединение Codex в соответствующем окне. В резервной копии есть
`manifest.json`: восстановите каждый `target` из указанного файла `backup`;
если `backup` равен null, удалите только этот добавленный установщиком файл.
Затем перезагрузите окно VS Code. Сохраните резервную копию и журналы задач.

Проверки и границы: [VALIDATION.md](VALIDATION.md).
